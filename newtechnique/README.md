## 打开哪个文件

### 想直接看网页版（推荐）

**双击 `index.html`** —— 会打开一个带侧边目录、代码高亮、思维导图的可交互手册，7 份材料一键切换。

> ⚠️ **如果双击打开是空白的**，说明浏览器出于安全限制不允许 `file://` 页面读取同目录的 `.md` 文件。
> 解决办法：在这个文件夹里起一个本地服务。
>
> 最省事的做法：**在这个文件夹的地址栏里输入 `cmd` 回车**（或按住 `Shift` 右键 → "在此处打开 PowerShell"），然后执行：
>
> ```
> python -m http.server 8080
> ```
>
> 再打开浏览器访问 **http://localhost:8080/index.html** 即可。
>
> （没装 Python 也行 —— 直接看下面的 `.md` 文件，内容完全一样。）

### `06-改简历数据-手把手教程.md` —— 操作单

**这份是给"不想学编程、只想改自己简历内容"的人写的。**

**特色**：明确标出哪些改法**会报错**、哪些改法**不报错但会悄悄出错**
（后者更危险，比如 `side` 写错了画会挂错墙，页面毫无提示）。

## 关于真实作品图（新增）

3D 长廊里原本挂的是**程序化生成的假画**（用 canvas 画的立方体、球体等）。
现在其中 3 幅换成了**真实作品图**——由 AI 生成的水墨画与油画：

| 图 | 内容 | 挂在哪幅画框上 |
|---|---|---|
| 水墨 · 墨潭跃鲤 | 一尾锦鲤从墨潭跃起，半工笔设色、半干笔解体 | 「关于我」 |
| 油画 · 行星静物 | 伦勃朗式明暗对照，带环的土星与地球装在木碗里 | 「技能」 |
| 水墨 · 山峦化猫 | 一只打哈欠的猫，身体由远山与雾构成 | 「项目作品」 |

**妙处在于**：hover 时会发生「素描 → 上色」的揭示。而真图本身
既不是素描也不是纯彩色稿——所以代码会**从同一张真图算出两份贴图**：

```
真实作品图
   ├─ painted  原图（微微提饱和）
   └─ sketch   去色 → Sobel 边缘检测 → 暗部排线 → 暗角
```

两者共享同一份像素坐标，所以上色时造型完全重合，**不会抖**。

> 这一步踩到一个非常隐蔽的坑：`file://` 下 `<img>` 能显示，
> 但 canvas 会被**污染**，`getImageData()` 抛 `SecurityError`。
> 表现是"页面完全正常，只是上色效果没了"，而且控制台只有一条 warn。
> 解法是把图片也 base64 内联。完整经过写在
> `01-新手实操手册.md` 的「第④道墙」那一节。

改造后的产物体积：

| 内容 | 体积 |
|---|---|
| `dist/index.html`（含字体 + 三张图） | **约 7.4 MB**（gzip 后约 5.0 MB） |

仍然是一个文件，双击即开、断网可用。

## 三条最重要的学习方法

### 一、一定要动手，不要只看

看一遍觉得"懂了"，敲的时候会发现一堆细节没注意到。

**每个阶段的练习，哪怕简单，也做一遍。**

### 二、遇到报错先看 Console

按 `F12`，看红色的报错。它会告诉你**第几个文件、第几行、什么错**。

看不懂就把红字复制去搜。**这一步能解决你 70% 的问题。**

### 三、允许自己"先抄对再理解"

先照着敲、让它跑起来、看到效果，**再**回头想为什么。

人对"我做出了一个东西"的记忆，远比对"我读懂了原理"的记忆牢固。
