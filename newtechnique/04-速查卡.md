## 三、F12 开发者工具

| 按哪个 | 看什么 |
|---|---|
| `F12` | 打开/关闭工具面板 |
| `Esc` | 在面板里开关 Console |
| `Ctrl + Shift + C` | 直接点页面上某个元素来检查它 |
| `Ctrl + Shift + R` | **强制刷新**（清缓存，样式不改时试试） |

### Console 常见红字翻译

| 报错 | 大概什么意思 | 怎么查 |
|---|---|---|
| `X is not defined` | 用了个不存在的名字 | 拼写错了？忘了 import？ |
| `Cannot read property 'x' of undefined` | 你以为是对象，实际是空的 | 往上一层，看那个东西为什么不空 |
| `Failed to load resource: 404` | 文件找不到 | 路径写错？文件没放对位置？ |
| `Port 5173 is already in use` | 端口被占了 | 找到旧的命令行窗口 `Ctrl+C` |
| `Uncaught SyntaxError` | 语法写错了 | 看它指的行号 |
| `Maximum update depth exceeded` | 死循环了 | `useEffect` 里改了自己依赖的东西 |

### 万能排查口诀

```
一、按 F12，看 Console 红字
二、把红字里的关键词复制去搜
三、还不懂，在可疑的地方写 console.log 看值
四、二分法：注释掉一半代码，看还错不错 —— 逐步缩小范围
```

## 六、⚠️ CSS 三大坑

### 坑 1：`position: fixed` 同时写 `top` 和 `bottom`

```css
/* ❌ 元素会纵向铺满整个屏幕 */
.back-home {
  position: fixed;
  top: 20px;
  bottom: 20px;
}

/* ✅ 只给 top，并且显式写 height: auto */
.back-home {
  position: fixed;
  top: 20px;
  left: 20px;
  height: auto;
}
```

**原理**：`fixed` 元素宽高默认自动，浏览器看到 `top` 和 `bottom` 都有值，就会**拉伸填满这两条边之间**。

### 坑 2：`margin` 塌陷

两个上下相邻的元素，各写 `margin-bottom: 20px` 和 `margin-top: 30px`，实际间距是 **30px**（取大的），不是 50px。

**解法**：用 Flexbox + `gap`，别用 margin 做间距。

### 坑 3：`height: 100%` 不生效

**原因**：父元素没有确定的高度。

**解法**：把整条链撑满：

```css
html, body, #root {
  margin: 0;
  padding: 0;
  width: 100%;
  height: 100%;
}
```

**或者用 `vh`**：`height: 100vh`（直接等于屏幕高度的 100%，不依赖父元素）。

## 九、React 速查

```jsx
// 组件（首字母必须大写！）
function MyCard({ title, children }) {
  return <div className="card"><h2>{title}</h2>{children}</div>
}

// 用组件
<MyCard title="你好">内容</MyCard>

// state —— 白板
const [count, setCount] = useState(0)
setCount(count + 1)        // ✅ 必须用 setter
// count = count + 1       // ❌ 绝不行，界面不会更新

// 副作用 —— 入住/退房
useEffect(() => {
  window.addEventListener('keydown', onKey)
  return () => window.removeEventListener('keydown', onKey)   // ← 必须清理
}, [])                     // [] = 只执行一次

// ref —— 抓对象，改了不重渲染
const ref = useRef()
return <mesh ref={ref} />

// 每帧执行（R3F 专用）
useFrame((state, delta) => {
  ref.current.rotation.y += delta    // ⚠️ 运动一定乘 delta
})
```

### ⚠️ 三条铁律

1. **`class` 要写 `className`**
2. **标签必须闭合** —— `<img />` 不能写 `<img>`
3. **组件名首字母必须大写** —— `myCard` 不行，必须 `MyCard`

## 十、⚠️ GLSL 三大坑

### 坑 1（最惨）：模板字符串里的反引号

```js
// ❌ 这个反引号会把字符串提前结束，后面变成 JS 代码，页面直接崩
const shader = `
  // 这里不能写 `smoothstep(...)`
  float x = smoothstep(0.0, 1.0, v);
`

// ✅ 注释里不要用反引号
const shader = `
  // 用 smoothstep 让边界柔和（参数 0.0 / 1.0 / v）
  float x = smoothstep(0.0, 1.0, v);
`
```

**最坑的地方**：`npm run build` **还是会绿**（因为构建不执行代码）。只有打开页面才崩。

### 坑 2：小数必须写 `1.0`

```glsl
float a = 1.0;      // ✅
float a = 1;        // ❌ 报错！GLSL 严格区分整数和浮点
```

### 坑 3：`replace` 找不到锚点静默失败

```js
// ❌ 锚点不存在时，原样返回，什么都不报
shader.fragmentShader = shader.fragmentShader.replace('#include <xxx>', '我的代码')

// ✅ 自己检查
shader.fragmentShader = shader.fragmentShader.replace('#include <dithering_fragment>', `...`)
if (!shader.fragmentShader.includes('我的函数名')) {
  console.error('[注入失败] 锚点可能变了')
}
```

### GLSL 常用函数

| 函数 | 作用 |
|---|---|
| `mix(a, b, t)` | 在 a、b 之间按 t(0~1) 插值 |
| `smoothstep(e0, e1, x)` | 把 x 从 e0→e1 映射成 0→1 的平滑曲线 |
| `clamp(x, lo, hi)` | 把 x 限制在 lo~hi 之间 |
| `fract(x)` | 取小数部分 |
| `floor(x)` | 向下取整 |
| `dot(a, b)` | 点积 |
| `length(v)` | 向量长度 |
| `texture2D(tex, uv)` | 采样一张贴图 |

## 十一、两个页面怎么连

**核心：`file://` 和 `http://` 是不同协议，跳转必须写完整绝对地址。**

```html
<!-- 从落地页跳 3D -->
<a href="http://localhost:5173" target="_blank" rel="noopener">3D 长廊</a>
```

```jsx
<!-- 从 3D 跳回落 地页 -->
<a href="file:///E:/fhgBLOG/IDEAblog/index.html">← 返回一念未落</a>
```

**演示前的固定流程：**

```
1. 命令行：cd /d E:\fhgBLOG\IDEAblog\portfolio-3d
2. 命令行：npm run dev          ← 这个窗口别关
3. 双击：E:\fhgBLOG\IDEAblog\index.html
4. 点页面上的「3D 长廊」
```

**`vite.config.js` 里建议加：**

```js
server: {
  port: 5173,
  strictPort: true,   // 端口被占用就报错，不许偷偷换到 5174
}
```

## 十三、遇到问题，按这个顺序查

```
① 页面上没有我要的东西
   → F12 → Elements → 那个元素在不在？
   → 不在：HTML 写错了 / 条件判断没进去
   → 在但看不见：CSS 问题（颜色、位置、大小、z-index、opacity）

② 样式不生效
   → Ctrl + Shift + R 强制刷新
   → F12 → Elements → 选中元素，看右边 Styles 面板里你的规则有没有被划掉
   → 被划掉说明有优先级更高的规则覆盖了它

③ 点击没反应
   → F12 → Console 有红字吗？（多半 had 报错，JS 中断了）
   → Console 里敲 document.getElementById("你的id") 看是不是 null
   → 检查 id 拼写、大小写

④ 3D 画面全黑/全白
   → Console 有报错吗？
   → 相机位置对吗？（别站在物体里面）
   → 有没有加灯光？（MeshStandardMaterial 没灯就是黑的）

⑤ 页面很卡
   → F12 → Performance 标签，录制几秒看看
   → 常见原因：useFrame 里创建了新对象、useEffect 没清理、贴图太大

⑥ 什么都不对，人麻了
   → 全部关掉，重新 npm run dev，强制刷新
   → 还不行：把最近改的代码注释掉，二分法定位
```
