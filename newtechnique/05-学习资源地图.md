## 怎么用这份材料

**不要想着"全看完"。** 那个想法会让你一个都看不完。

正确用法：

```
① 在 01-新手实操手册 里做到某个阶段 → 卡住了
② 打开这份材料，找到对应分类
③ 挑一个看着最顺眼的，看 1~2 个视频或 1 篇文章
④ 回去继续做
```

**每个知识点，官方文档永远是最准的**（因为作者最清楚自己写的东西）。视频适合入门建立直觉，官方文档适合查细节。

## 1. 总入口：从这里开始

### MDN Web 开发者学习区 ⭐ 最推荐新手

**https://developer.mozilla.org/zh-CN/docs/Learn**

Mozilla（火狐浏览器那家）官方出的**中文**教程。从"什么是网页"讲起，循序渐进，质量极高，**完全免费无广告**。

**为什么推荐它**：很多中文教程是二手翻译，概念会被讲歪。MDN 是**一手资料**，而且中文翻译质量在同类里最好。

**怎么用**：从左侧目录的「HTML - 构建 Web」「CSS - 为 Web 设置样式」「JavaScript - 动态客户端脚本」三块依次看。

---

### 菜鸟教程

**https://www.runoob.com/**

**特点**：中文、简洁、有在线运行环境（可以边看边改代码试）。

**适合**：想快速查一个语法怎么写。比如"CSS 怎么加阴影"，搜一下就有例子。

**不适合**：系统学习（讲得比较浅，原理阐述少）。

---

### W3School 中文版

**https://www.w3school.com.cn/**

老牌教程站，和菜鸟教程定位类似。

**特点**：每个知识点都有一个「试一试」按钮，能直接改代码看效果。

**和菜鸟教程的区别**：两个都可以用，哪个搜到用哪个，内容大差不差。

## 4. Three.js / 3D

### Three.js 官方手册（有中文）⭐ 最推荐

**https://threejs.org/manual/#zh/fundamentals**

**注意网址里的 `#zh`** —— 这是中文版！很多人不知道 Three.js 官方手册有中文，白啃英文。

**推荐顺序**：
1. `#zh/fundamentals` —— 最基础的场景搭建
2. `#zh/installation` —— 怎么安装（用 npm 还是 CDN）
3. 左侧目录往后翻，讲光照、贴图、阴影、动画

**特点**：每章都有**可运行的完整代码**，可以直接复制下来改。

---

### Three.js 官方文档（API 参考）

**https://threejs.org/docs/**

**用途**：查具体的类和方法的参数。

⚠️ 左上角有个语言切换，但**中文翻译不全**。查 API 时看英文更靠谱，配合浏览器翻译插件看。

**常见查询**：
- `PlaneGeometry` —— 平面几何体的参数
- `MeshBasicMaterial` —— 基础材质有哪些属性
- `WebGLRenderer` —— 渲染器的配置项

---

### Three.js 官方示例库 ⭐ 强烈推荐

**https://threejs.org/examples/**

**这是我最推荐的资源。** 官方做了几百个可交互的 3D 例子，涵盖各种效果。每个例子都能看源码。

**怎么用**：

1. 打开逛，看到喜欢的效果就点进去
2. 页面右下角有个 `</>` 图标，点开是**完整源码**
3. 复制出来，删删改改，看每个参数控制什么

> **这是学 3D 最高效的方式**：不要从"学完所有 API 再做"，而是"看到一个效果 → 拆开它 → 改成自己的"。

**值得先看的例子**（在列表里搜关键词）：
- `webgl_geometry_cube` —— 最基础的立方体
- `webgl_materials_texture_anisotropy` —— 贴图
- `webgl_shader` —— 自定义着色器入门
- `webgl_postprocessing` —— 后期处理

---

### WebGL 基础（中文）

**https://webglfundamentals.org/webgl/lessons/zh_cn/**

讲 **WebGL 底层原理**（Three.js 是它的封装）。

**什么时候看**：当你想知道"Three.js 内部到底做了什么"、"矩阵变换是怎么回事"。

**重要提示**：**不要一开始就看这个。** 先会用 Three.js，好奇原理了再来看。否则会被大量数学劝退。

---

### LearnOpenGL 中文版

**https://learnopengl-cn.github.io/**

讲现代图形学的基础（光照模型、阴影、法线贴图等）。

**什么时候看**：想深入理解 3D 渲染原理时。**同样不建议一开始看。**

## 5. GLSL 着色器

### The Book of Shaders（有中文）⭐ 最推荐

**https://thebookofshaders.com/?lan=ch**

**学着色器最好的免费资料，没有之一。** 有中文版。

**它好在哪**：

- **每一章都有在线编辑器**，左边改代码右边立刻看效果 —— 不用配环境就能开始玩
- 从"什么是像素"讲到噪声、随机、分形，**循序渐进**
- 讲噪声的那几章（第 10~13 章）**跟本项目的"上色揭示"效果直接相关**

**推荐顺序**：

1. 「算法绘画」—— 理解片元着色器在干什么
2. 「颜色」—— `vec3` 怎么用
3. 「形状」—— 用 `smoothstep`、`step` 画图形
4. 「随机」—— `hash` 函数
5. 「噪声」⭐ —— **本项目的核心，重点看**
6. 「分形布朗运动」⭐ —— 多层噪声叠加

**这书的节奏很慢、很友好，适合新手。**

---

### ShaderToy ⭐ 强烈推荐

**https://www.shadertoy.com/**

一个在线着色器游乐场。里面有几万个别人写的着色器，都能直接看源码、直接改。

> ⚠️ 这个站反爬比较严，某些网络环境下可能打不开。打不开就跳过，The Book of Shaders 够用了。

**怎么用**：

1. 首页随便点一个作品，看效果
2. 点下面的代码区域，就能改，**改完立刻看效果**
3. 想学某个效果，就"抄"它的代码，然后**逐行删掉看会怎样** —— 这是理解着色器最快的方法

**搜索建议**：搜 `noise`、`pencil`、`sketch`、`ink`，能看到和本项目类似的画笔触效果。

---

### GLSL 速查

**https://www.shaderific.com/glsl-functions/**

GLSL 内置函数的清单和说明（英文）。查"有没有现成函数能用"时很方便。

## 8. GSAP 动画

### GSAP 官方文档

**https://gsap.com/docs/v3/**

本项目开场"纸张撕裂"动画用的是 GSAP。

**最该看的**：
- **GSAP 3 入门** —— `gsap.to()` 怎么用
- **Timeline 时间轴** —— 怎么把多个动画串起来（本项目撕纸用的就是这个）
- **Easing 缓动** —— 让动画有"手感"

**特别说明**：GSAP 的 `timeline` 是它的核心能力 —— 可以把多个动画排成一条时间线，指定谁先谁后、谁和谁同时，这是做复杂动画的关键。

## 10. 视频教程怎么找

**视频适合入门建立直觉，不适合当参考书。** 看完要动手，光看没用。

### B 站（首选）

**https://www.bilibili.com/**

**为什么首选**：免费、中文、量大、有弹幕可以看别人在哪卡住。

**搜索关键词建议**（直接复制去搜）：

| 想学什么 | 搜这些 |
|---|---|
| 前端入门 | `前端 零基础`、`HTML CSS 入门`、`Web 前端 教程` |
| JavaScript | `JavaScript 基础`、`JS 从入门到精通` |
| Three.js | `Three.js 教程`、`Three.js 入门`、`WebGL 3D` |
| 着色器 | `GLSL 教程`、`Shader 入门`、`着色器 教程` |
| React | `React 入门`、`React Hooks 教程` |
| R3F | `React Three Fiber`、`R3F 教程` |
| Vite | `Vite 教程`、`Vite 入门` |

**怎么挑视频**：

1. **看发布时间** —— 前端变化快，**两年前的 React 教程可能已经过时**（比如还在用 class 组件）。优先近一年的。
2. **看时长** —— 太短（10 分钟）的只能讲个皮毛；太长（100 小时）的看不完。**系列视频，单集 20~40 分钟比较合适**。
3. **看播放量和收藏数** —— 收藏率高（收藏/播放 > 10%）的通常干货多。
4. **先看前 5 分钟** —— 讲得清楚就继续，一上来就念 PPT 的换一个。

**推荐找法**：在 B 站搜 `Three.js 教程`，然后按「最多收藏」排序，选最前面的那一两个。

## 12. 参考项目

### 本项目的参考原型

**https://github.com/ITomPoland/portfolio-itom**

本项目（portfolio-3d）的参考原型。它是一个 3D 交互式作品集网站，带开场动画、无限走廊、画框交互。

**怎么学**：

⚠️ **不要一上来就读它的源码。** 会看不懂，然后放弃。

**建议这样**：
1. 先按 `01-新手实操手册` 自己做完一遍
2. 然后打开这个仓库，**只看你这次做过的部分**（比如撕纸动画怎么写的）
3. 对比找差异：**"我这样写的，他那样写的，他为什么那样？"**

> **读源码的正确姿势**：不是从第一行读到最后一行，而是**带着问题去搜**。比如"我想知道他的撕纸动画用了几秒"→ 搜 `duration` → 找到 → 看上下文。

## 学习路线建议

**如果你是完全的新手**，按这个顺序：

```
第 1 周  MDN 学习区「HTML 基础」+「CSS 基础」
         + 玩 Flexbox Froggy
         目标：能做出一个静态的介绍页

第 2 周  MDN 学习区「JavaScript 基础」
         + 01 手册的阶段 0~2
         目标：做出一个能点击交互的页面

第 3 周  Three.js 官方手册（#zh 前 4 章）
         + Three.js 官方示例库随便逛
         目标：看懂并改动能跑 3D 的例子

第 4 周  Vite 中文文档 + 01 手册阶段 4~5
         + React 官方文档「快速入门」「用 React 思考」
         目标：能建 Vite 工程，看懂 R3F 组件

第 5 周  The Book of Shaders（中文版）第 1~13 章
         + 01 手册阶段 6
         目标：理解着色器原理，能改噪声参数
```

**每周结束时，确保自己"留下一个能跑的东西"。** 这比"看了多少"重要得多。

## 最后：怎么"正确地搜"

90% 的问题，正确的搜索方式就能解决。

**搜索公式**：

```
技术名 + 具体问题 + 错误关键词
```

| ❌ 不好的搜法 | ✅ 好的搜法 |
|---|---|
| "CSS 不会写" | `CSS flex 水平垂直居中` |
| "JS 报错" | `JavaScript Uncaught TypeError cannot read property of undefined` |
| "3D 不显示" | `threejs mesh 不显示 相机 位置` |
| "React 有问题" | `React useEffect 无限循环依赖` |
| "Vite 打不开" | `Vite port 5173 is already in use` |

**三条搜技巧**：

1. **报错信息直接整段复制去搜** —— 报错都是标准化的，别人一定遇到过
2. **加 `site:developer.mozilla.org`** —— 只在 MDN 里搜，结果更权威
3. **英文搜不到再搜中文** —— 编程问题英文资源一定是中文的十倍以上，能用英文搜就用英文

**搜不到怎么办**：

- 换个说法再搜（"居中" → "center" → "alignment"）
- 去 B 站搜相关视频，看别人怎么做的
- **把问题描述清楚，去问 AI** —— 描述里带上：你想做什么、你写了什么代码、报了什么错、你试过什么
